Game Save Backup Tool - portable build
========================================

Extract this folder anywhere (USB drive, D:\Tools, etc.) and run:

  gsbt-main.exe   (desktop GUI)
  gsbt.exe       (terminal CLI)

No installer required. This build is self-contained (.NET 10 + Windows App SDK bundled).

Prerequisite: none
------------------
No separate .NET or runtime install is required.

The GSBT Setup installer installs the same files under:

  %LocalAppData%\Game Save Backup Tool\

(per-user, no admin - like PowerToys-style tools).

Screen saver media
------------------
Bundled as data\screensaver.7z (not loose video/audio files). On first use the app
extracts media to your user profile cache under Game Save Backup Tool.

Sandbox (optional developer mode)
---------------------------------
  gsbt-sandbox.exe   (blue-icon GUI apphost with sandbox monitor enabled)
  gsbt-main.exe -s    (equivalent runtime behavior)

Settings and data
-----------------
  %AppData%\Game Save Backup Tool\winui\

Uninstall
---------
Delete this folder. Your settings in %AppData%\Game Save Backup Tool remain until you remove them.
